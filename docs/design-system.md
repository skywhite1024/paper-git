# PaperGit 明亮学术风格

设计围绕阅读和研究路线。首页按用户选定的「2D-07 研究群岛地图」实现：暖白纸面、柔和等高线、论文缩略卡与右侧解读面板。保留 Claude 类界面的暖白纸感，以及 [paper-figure/output/aspire](https://github.com/skywhite1024/paper-figure/blob/main/output/aspire/aspire-figure-1.png) 的浅色学术分组。地图与装饰使用原生 SVG；论文框架图独立取自对应官方项目／论文并明确署名。

群岛首页单独采用世界模型 `#548473`（浅绿）、VLA `#B4844E`（暖杏）、Agent `#8C79A6`（淡紫）；当前选中节点用蓝色描边，避免与主题分组混淆。原有资料库与阶段页面的类别色保持不变。

色彩不单独承担意义：每条路线均有编号与名称，论文类型及荣誉有文字徽标，阅读状态也显示文字。连接箭头表达推荐阅读顺序，不表达未经核验的引用关系。

## 布局

- 暖白背景、细描边、适量留白。主标题使用本地衬线字体；正文采用系统无衬线字体，不请求外部字体。
- 桌面首页分为地图与论文解读两栏；1180px 以下垂直堆叠，避免窄栏裁切地图。手机地图保持可读的最小画布，可在地图内部滑动，不撑宽页面。
- 地形与连线用 SVG，论文入口为原生 HTML 按钮，支持键盘访问。默认 9 个地标，完整 43 篇通过搜索和可展开索引访问。
- 搜索支持名称、标题、简介、入选理由、年份与会议；可叠加方向及年份筛选。选择非地标论文后替换其主题中的一个展示位置。
- 解读面板含框架原图、三步读图、贡献／差异／局限、相关阅读、方法对照和原有笔记编辑器。9 篇地标有完整图示与结构化对照，其余内容显示补充状态与原文入口。
- 框架图支持原生 dialog 放大、Esc 关闭和来源链接。图片本地托管，并随 GitHub Pages 的 base path 导出。
- 不保留深色主题或自动跟随系统的暗色切换。
- 可聚焦控件提供可见轮廓，尊重 prefers-reduced-motion。
- 没有背景视频、远程装饰图片、动态粒子或无目的自动动画。

## 内容边界

研究路线依据项目与论文证据，结合用户提供的 8 份可lip文字稿组织。来源页逐项记录阅读范围与路线关联，详细调整见 transcript-review.md；原始转写不替代学术事实核验。

实线是建议阅读，虚线是方法对照；连线不声称引用或严格继承关系。π0 归属 VLA，框架原图对应 2024 年初稿，目录年份沿用正式 RSS 2025 发表年份。图片出处、原始文件 URL 和图示版本记录在 `frontend/content/frameworks.json` 及 `frontend/public/figures/README.md`。不将样例中的示意文字当作论文事实。
