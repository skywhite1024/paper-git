# PaperGit 明亮学术风格

设计围绕阅读和研究路线。首页按用户选定的「2D-07 研究群岛地图」实现，并于 2026-10-27 调整为自由画布：暖白纸面、柔和等高线、以框架图为主的工作卡片与可收起的浮动解读。保留 Claude 类界面的暖白纸感，以及 [paper-figure/output/aspire](https://github.com/skywhite1024/paper-figure/blob/main/output/aspire/aspire-figure-1.png) 的浅色学术分组。地图与装饰使用原生 SVG；论文框架图独立取自对应官方项目／论文并明确署名。

色彩不单独承担意义：每条路线均有编号与名称，论文类型及荣誉有文字徽标，阅读状态也显示文字。连接箭头表达推荐阅读顺序，不表达未经核验的引用关系。

## 布局

- 暖白背景、细描边、适量留白。主标题使用本地衬线字体；正文采用系统无衬线字体，不请求外部字体。
- 地图占据整个主区域，也可全屏展开；解读以可收起的浮层打开，不缩小地图。手机保持相同的自由画布，解读浮层按屏幕宽度适配，不撑宽页面。
- 地形与连线用 SVG，论文入口为原生 HTML 按钮，支持键盘访问。全部 43 篇都有固定位置，按三个岛与各岛四个阶段分组，卡片尺寸 320 × 230，图像区约 300 × 163。工作名缩为 15px 的图下说明，不再使用大标题加小缩略图。
- 相机使用平移与缩放变换，不依赖有限容器的滚动范围。平移不设边界，缩放为 5%–250%；鼠标锚点缩放、双指中点缩放和窗口缩放时保持位置连续。小地图、全览与按岛导航用于找回位置。
- 搜索支持名称、标题、简介、入选理由、年份与会议；可叠加方向及年份筛选。未匹配节点淡化以保留方位，搜索结果和索引直接定位已有节点，不移除或替换论文。
- 解读面板含框架原图、三步读图、贡献／差异／局限、相关阅读、方法对照和原有笔记编辑器。9 篇地标有完整图示与结构化对照，其余内容显示补充状态与原文入口。
- 框架图支持原生 dialog 放大、Esc 关闭和来源链接。图片本地托管，并随 GitHub Pages 的 base path 导出。
- 不保留深色主题或自动跟随系统的暗色切换。
- 可聚焦控件提供可见轮廓，尊重 prefers-reduced-motion。
- 没有背景视频、远程装饰图片、动态粒子或无目的自动动画。

画布手势与论文点击用移动阈值区分，从图片上拖动不会打开论文。容器使用 `overflow: clip`，避免浏览器在按钮获得焦点时叠加原生滚动，使相机偏移。键盘聚焦屏幕外的论文时会定位到对应卡片。新增几何测试覆盖全部论文的归属、无重叠、缩放锚点和不同屏幕下的全览范围。

## 内容边界

研究路线依据项目与论文证据，结合用户提供的 8 份可lip文字稿组织。来源页逐项记录阅读范围与路线关联，详细调整见 transcript-review.md；原始转写不替代学术事实核验。

实线是建议阅读，虚线是方法对照；连线不声称引用或严格继承关系。π0 归属 VLA，框架原图对应 2024 年初稿，目录年份沿用正式 RSS 2025 发表年份。图片出处、原始文件 URL 和图示版本记录在 `frontend/content/frameworks.json` 及 `frontend/public/figures/README.md`。不将样例中的示意文字当作论文事实。
