# 三维知识拓扑与提示词系统（v3 重构）

> 本次重构目标：放弃二维大画布方案，主可视化改为**三维立体知识结构拓扑图**；
> 重建提示词/文案系统以去除模板化痕迹；增强图结构的广度与可扩展性。

## 一、三维拓扑的结构隐喻

确定性布局（`frontend/lib/layout3d.ts`），不用物理模拟，坐标由数据唯一决定：

```
Z 轴：六条「路线走廊」并行排布（每条路线一条走廊，入口竖立路线名牌）
X 轴：阶段「地层」沿走廊推进（1→N 层，薄板标号；hub→阶段→阶段 构成 pipeline 结构边）
Y/Z：地层上的方法节点按晶格排布（每层 5 个沿 Z，超出向 Y 抬升——「标本架」结构）
```

- **路线思路与逻辑的读法**：沿任一走廊从入口向深处推进即该路线的主流程；
  走廊内地层间的曲线管为演进/使能关系（蓝/绿），跨走廊高拱紫管为闭环回流
  （任务生成→探索/示范归纳、技能库→新发现）。双击复位视角后俯瞰即为全局脉络。
- **可扩展性**：新增路线 = 新走廊（Z 轴自动排布），新增阶段 = 沿 X 轴延伸地层，
  新增路线族 = 新的走廊组团；布局引擎对节点数为 O(n)，无布局退化问题。

## 二、渲染与交互（`components/Topology3D.tsx`，three.js 直用）

- 场景元素：走廊地面与边线、阶段薄板与编号、路线名牌（Canvas 纹理精灵，支持中文）、
  发光球体节点（关键工作更大更亮并缓慢自旋）、贝塞尔管状边（pipeline 淡、演进亮、loop 高拱）。
- 取景：`lib/layout3d.ts` 输出包围盒与包围球，`fitFrame` 按容器宽高比逐角点反解透视，
  求出让整个盒体入镜的机位距离与注视点；`frameBoxFor` 再按当前可见走廊收缩取景盒，
  使单走廊视图自动推近。
- 标签：精灵尺寸按视深换算为**恒定屏幕像素**（缩放不放大字号）；`renderLabels` 做屏幕空间
  贪心避让，优先级为 选中 > 走廊 > 阶段 > 层号 > 方法，近处遮挡远处；
  右对齐的走廊名牌会把锚点钳制回画布内，避免越过左右边界被裁。
- 主题：场景背景、雾、文字色取自 CSS 变量（`--c-*`），并监听 `<html data-theme>` 重绘，
  因此深浅色切换无需重建场景。
- 交互：OrbitControls（旋转/缩放/平移，阻尼）；射线拾取悬停（浮动提示卡）与单击选取；
  相机飞行（选取/定位时平滑飞至节点）；双击复位；键盘方向键遍历节点、Enter 选取、Esc 取消。
- 外壳（`components/TopologyExplorer.tsx`）：右侧详情面板（论文/阶段/路线三类内容）、
  画布**下方工具条**承载图例与走廊显隐筛选、三维/列表视图切换、
  「定位节点」下拉直达、`?route=&node=` 深链。图例不再浮在画布上，避免遮挡走廊。
- 降级：WebGL 不可用或三维子树抛错时，回落为 `components/Topology2D.tsx` 列表视图，
  而非黑屏。

## 三、图结构扩展（后端）

`GET /api/routes/graph/network` 在枢纽 + 方法节点 + 演进/闭环边之外，新增：

- **阶段锚点节点**（kind=stage，每阶段一个，含阶段说明与论文计数）——可点击，
  HUD 直接展开「该阶段涉及的全部文章」；
- **pipeline 结构边**（hub→阶段1→…→阶段N），把六条走廊串成可读的推进链；
- 三类节点 + 五类边（evolve/enable/compare/pipeline/loop）构成可无限扩展的图模型。

## 四、提示词系统（`frontend/lib/lexicon.ts`）

全站文案收敛到统一词表：导航、检索、拓扑操作说明、HUD 各区块标题（路线走廊/阶段地层/
代表工作/上游脉络/下游脉络/同阶段工作）、领域树页与卡片用语。语气规范：学术中性、
中文为主英文辅注、禁用表情符号、不写「点击这里」式空话。视觉同步收敛：
移除全部 emoji 图标与星号标记（改为「里程碑」「关键工作」文字徽标）、路线以色块标识。
