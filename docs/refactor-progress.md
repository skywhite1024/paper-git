# 个人研究资料库重构

目标：围绕世界模型、VLA、Robot Agentic 整理个人阅读资料，替换原有全领域聚合与技能发现图谱。当前工作以用户最新目标为准。

## 验收要求

- [x] 首页只展示三条主线，各四个阶段；阅读顺序、路线交汇关系与 WM / VLA / WAM 对照明确。
- [x] 31 篇正式论文以相关重要会议为主；CCF 2026 版本明确，RSS / CoRL 单列领域收录理由，补充 Nature / TMLR。
- [x] 5 个 Oral / Spotlight / Best Paper 标记有来源；不把入围或 workshop 荣誉写成主会获奖。
- [x] 8 篇关键技术报告独立分类；4 篇 2026 预印本有入选理由与项目 / 实现入口。
- [x] 已阅读用户提供的 8 份可lip文字稿；七份主题稿通读，合集去重比对后补读差异。阅读范围及对应调整见 transcript-review.md 和来源页。
- [x] 16 个配套资源入口，覆盖数据、代码、仿真、基准与导读；支持本地阅读状态、笔记和 JSON 备份。
- [x] 运行只依赖本地内容，移除旧自动抓取、全领域分类、API 服务和联网 Agent 入口。
- [x] `npm run dev` 启动并调用默认浏览器；`--no-open`、端口占用提示、Ctrl+C 停止与重启已验证。
- [x] 目录与笔记测试 7 项通过；类型检查与 54 个静态页面的生产构建通过；桌面与手机浏览器交互已验证。

## 实现决定

采用 Next.js 单应用和人工维护的 JSON 资料目录。首页使用可直接阅读的二维阶段流程，论文详情保留学术证据与阅读提示。外部原文只在用户点击链接后打开，不在运行时抓取或调用模型。原 SQLite 文件保留在 data/，不自动搬入精选目录。

## 已知边界

资料导读是个人阅读入口，原始来源核验不等于逐篇全文精读或独立复现。阅读笔记保存在浏览器 localStorage，需主动导出备份；不同来源和浏览器之间不自动同步。没有自动收录与联网 Agent。
