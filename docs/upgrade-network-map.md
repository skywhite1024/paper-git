# 升级方案：论文网络大画布主页（Network Map）

> 对应需求：① 主页面为广阔可交互的论文网络图；② 内容以图表形式呈现各阶段关键图示；
> ③ 图示含论文架构图、阶段涉及的文章可展开；④ 大画布铺开或 3D 立体网络。

## 一、可行性分析

### 结论：方向合理，2D 结构化大画布 + 3D 力导图双模式是当前最优解。

1. **为什么不做纯力导向 2D 图**：力导向布局每次刷新位置随机，「思路清晰」要求布局稳定可预期。
   采用**确定性宏观布局**——路线为纵向列、阶段为横向带（类似地铁图），演进边自然从左向右流动，
   用户可预期地"从左读到右就是时间/逻辑演进"。3D 模式补充自由空间探索的沉浸感。
2. **数据规模完全可行**：当前路线网 6 条路线 / 126 个方法节点 / 28 条演进边 + 闭环边，SVG 渲染毫无压力；
   即使未来扩展到 10 个路线族、2000 节点，SVG + 视口裁剪或 Canvas 仍可承载（现有组件已按此预留）。
3. **论文架构图的版权与现实约束**：论文原图版权归作者/出版方，热链 arXiv 页面图片不稳定。
   方案分三层：
   - **现在**：自绘**阶段示意小图**（StageDiagram，按阶段类型生成的 SVG 原理图）+ 论文 arXiv 链接；
   - **数据层已支持** `figure_url` 字段：后续把自截图的架构图放 `frontend/public/figures/` 即可在面板展示；
   - **远期**：接入 arXiv HTML 版本的图片抽取（`arxiv.org/html/<id>`），按需缓存并标注来源。
4. **3D 的取舍**：3d-force-graph（three.js）成熟可靠，但 3D 中阅读标签与精确点击效率低于 2D。
   因此 3D 定位为"空间总览/演示模式"，2D 为工作模式，一键切换。

### 不做的事（明确排除）

- 不做无限白板式自由拖放（tldraw 类）：维护成本高且与"路线即代码"的确定性数据模型冲突；
- 不默认抓取论文原图：版权与稳定性风险，改为 figure_url 白名单机制。

## 二、实现方案（本次落地）

### 后端

- 新增 `GET /api/routes/graph/network`：一次性聚合全部网络数据——
  6 个路线枢纽节点（hub）+ 126 个方法节点（paper，含路线/阶段/年份/链接/备注/figure_url）+
  28 条演进边（evolve/enable/compare）+ 3 条闭环语义虚边（taskgen→usd、taskgen→demo、compose→usd）。
- 数据仍来自 `routes/routes.yaml`（路线即代码），新增节点字段 `figure_url` 可选支持。

### 前端

1. **主页面 `/` 重构为网络图主页**：
   - 顶部统计条（论文总数/节点数/路线数）+ 全局搜索入口；
   - 主体为 2D 大画布 `NetworkMap`：路线列 × 阶段带的确定性布局，总画布约 3600×1500px，
     支持滚轮缩放、拖拽平移、双击复位；悬停高亮上下游；点击节点/枢纽展开右侧详情面板；
   - 图例：按路线着色/过滤；URL 支持 `?route=usd` 进入单路线聚焦视图（路线页提供跳转链接）；
   - 「2D / 3D」切换：`NetworkMap3D` 用 3d-force-graph 渲染同一数据，节点可点击（同一详情面板）。
2. **右侧详情面板（可展开）**：
   - 论文节点：标题/年份/一句话贡献/全称/arXiv 链接/figure_url 架构图（如有）/
     StageDiagram 阶段示意小图/上下游演进列表（可点击跳转定位）；
   - 阶段展开：「该阶段全部论文」列表，逐个可点选定位；
   - 枢纽节点：路线简介、主流程管线、洞察引文、跳转路线页按钮。
3. **路线页 `/routes/[id]` 增强**：阶段卡片附 StageDiagram 小图与该阶段论文 chips（点击定位到网络图）。

### 交付验证

- `pytest` 全量通过（含 graph/network 端点测试）；
- `next build` 成功；`/`、`/?route=usd`、`/routes`、`/routes/usd`、`/nodes/ai` 等页面 200；
- 2D 画布缩放/平移/点击、3D 初始化与节点点击、详情面板展开——经页面与接口双重验证。

## 三、后续演进

- figure_url 批量补图（从 arXiv HTML 抽取首图，人工确认后入库）；
- 网络图与论文语料库打通：方法节点 ↔ papers 表按 arXiv id 关联，显示引用数与相关论文；
- 更多路线族（LLM 推理 / VLA 等）以 YAML 并列加入，`/` 自动聚合为多族大图；
- 画布支持 minimap、节点搜索自动定位、布局方案切换（地铁图/聚类图/时间轴图）。
